The session file is `sessions/<encoded-cwd>/<uuid>/updates.jsonl`. `summary.json` is the companion for cwd, title, and model, including a group directory that is a slug plus a hash and a `.cwd` file when the encoded cwd exceeds 255 bytes.

### What the page states
Home is `GROK_HOME`, otherwise `~/.grok`, with no XDG fallback, and a relative `GROK_HOME` is used as given. Sessions are `sessions/<encoded-cwd>/<uuid>/`. The group name is uppercase-hex percent-encoding of the cwd. Past 255 bytes it is slugify of the leaf, a hyphen, and the first 16 hex characters of BLAKE3 of the cwd, with a `.cwd` file holding the original path. `updates.jsonl` is the transcript. `summary.json` is the companion (`info.cwd`, `generated_title` else `session_summary`, `current_model_id`). The native id is the UUID. Sync uploads `transcript_jsonl` and `summary_json` only. Normalize projects `updates.jsonl` onto schema_version 1: `session/update` and `_x.ai/session/update`; coalesced message chunks; `tool_call`; `tool_call_update` only when completed or failed. Other methods and sessionUpdate values are skipped. `session_id` is `grok:` plus the UUID. Reader version is `1`, with no confidence field. Cursor IDE and Cursor CLI stay separate corpora, including when a Cursor session used a Grok model.

The fourth acceptance criterion held the projector out until normalize landed. It has landed, so the page names it.
