## Description

Lets an operator record that a refused project was reviewed and will not be imported, so it leaves the review queue.

- **Hide** and **Unhide** on `/review` rows, singly or by checkbox selection, with an optional note. The same Hide appears on refused rows of a device's page.
- The operator role is required. The form is CSRF-checked. No recent re-authentication is needed, since hiding adds no access.
- A hide is lake-wide, keyed by git remote or cwd, per the epic's decision. The confirmation says how many devices hold each project.
- A hidden project that a profile later allows drops out of the Hidden tab naturally. A hide never blocks an allow.
- `POST /api/web/v1/review/hide` and `/unhide` take a list of keys and answer with what changed. Documented in `docs/web-api.md`.
- The Hide button says it changes only what the dashboard shows and does not stop the agent. A deny rule on the profile does that.

## Acceptance criteria

- [ ] Operators hide and unhide one or many projects with an optional note
- [ ] A hidden project leaves Needs review on every device
- [ ] The page says a hide does not stop the agent
