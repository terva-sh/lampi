## Description

Training projection strips secrets; raw CAS retained for legal/replay.

## Acceptance criteria

- [x] The training projection strips secrets
- [x] Stripping applies to the normalized training view only
- [x] Raw CAS is retained for legal/replay

## Implementation plan

`terva-lampi export --format sharegpt` and `--format trajectory` already share one training projection, `normalize.ShareGPT`. `--format events` writes the derived JSONL and does not call that function. That split stays.

Ruleset v1 stays the scanner. `Ruleset.Strip` returns a copy of a string with each v1 match replaced by `[redacted:<rule>]`. The placeholder names the rule and does not contain the matched text. Overlapping matches keep the earliest, longest span. `Scan` is unchanged: it still counts hits, records rule names, and does not rewrite the buffer. The upload path does not call `Strip`, so quarantine and `redaction.upload_hits` stay as they are.

`ShareGPT` runs `Strip` on the plaintext training fields of each turn: `value` (from `content_text`), `name`, and `call_id`. `encrypted_content` is copied as stored and is not scanned or decrypted. `raw_sha256`, the session id, and the project id are not rewritten. The events passed in are not mutated. The CAS blob and the normalized JSONL on disk are not opened for write.

A session that is not allowlisted is still omitted. Default deny and deny-wins stay as they are. No new flag.
